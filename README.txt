ROYAL MAROON & GOLD — MEHFIL-E-NIKAH INVITATION

Files:
- index.html: complete standalone responsive invitation website.

How to preview:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For sharing online, upload the folder to any static website host (for example GitHub Pages, Netlify, or your own hosting).

Features:
- Animated envelope opening, plus skip and replay controls.
- Responsive invitation sections and countdown.
- Google Maps search link for the venue.
- WhatsApp sharing.
- Optional original, browser-generated ambient tones. No external audio file or autoplay is used; guests start it with the music button.

Accuracy note:
The website uses the details legible in the supplied invitation image. No reception or additional ceremony has been added. The original card gives the venue as “B. Convention Centre, Near Andhra Muslim College, Ponnur road, Guntur”; the Maps button searches that exact wording and does not claim a verified venue pin.
